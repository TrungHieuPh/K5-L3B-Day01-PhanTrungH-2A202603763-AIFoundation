3. f1_example:
   - TP = 80, FP = 20, FN = 40
   - Precision = 80 / (80 + 20) = 0.80
   - Recall = 80 / (80 + 40) ≈ 0.67
   - F1 = 2 * (Precision * Recall) / (Precision + Recall)
     F1 = 2 * (0.80 * 0.67) / (0.80 + 0.67) ≈ 0.73

4. cosine_example:
   - v1 = [1, 2, 0], v2 = [2, 1, 2]
   - Dot product = (1*2) + (2*1) + (0*2) = 4
   - ||v1|| = √(1² + 2² + 0²) = √5 ≈ 2.24
   - ||v2|| = √(2² + 1² + 2²) = √9 = 3
   - Cosine = 4 / (2.24 * 3) ≈ 0.60
